# engAIge Social Media Post Author

Generate authentic social media post histories for NPCs across all platforms (MyFace, InstaSnap, Threadit). Creates content that feels like it existed before the player joined.

## Import Path

Posts are inserted into the `posts` table in `game.db`. There is no file-based auto-import for posts — they must be inserted via SQL or a seed script. Generate JSON matching the exact DB schema below.

## Output Format

**CRITICAL:** Field names MUST match the `posts` table columns exactly (snake_case).

Each post is a JSON object. Output as an array for batch import:

```json
[
  {
    "npc_id": "npc_id_here",
    "platform": "myface",
    "content": "The post text here",
    "media_urls": "[]",
    "likes_count": 12,
    "comments_count": 3,
    "shares_count": 0,
    "created_at": 1738540800,
    "content_rating": "normal"
  }
]
```

### Field Reference

| Field | Required | Type | Notes |
|-------|----------|------|-------|
| `npc_id` | **Yes** | string | Must match an existing NPC `id` in the `npcs` table. |
| `platform` | **Yes** | string | One of: `myface`, `instasnap`, `threadit` |
| `content` | **Yes** | string | The post text. |
| `media_urls` | No | string | JSON-encoded array of image descriptions/URLs. Default `"[]"`. |
| `likes_count` | No | integer | Default 0. |
| `comments_count` | No | integer | Default 0. |
| `shares_count` | No | integer | Default 0. |
| `created_at` | Yes | integer | **Unix timestamp in seconds.** Use past timestamps for historical posts. |
| `content_rating` | No | string | One of: `harsh`, `strict`, `normal`, `relaxed`, `none`. Default `normal`. |

### Fields That Do NOT Exist

Do NOT include these — they are not in the database:
- ~~`author_id`~~ — Use `npc_id` instead.
- ~~`created_at_offset_hours`~~ — Not a field. Calculate and use a real unix timestamp for `created_at`.
- ~~`mood`~~ — Not a DB column. Mood should be expressed through post content/tone.
- ~~`id`~~ — Auto-generated by the import process.
- ~~`engagement_score`~~ — Calculated at runtime, not seeded.

### Timestamp Helper

To calculate `created_at` for a post from N hours ago:
```
current_unix_timestamp - (N * 3600)
```

Example: 3 days ago from Feb 5 2026 00:00 UTC (1738713600):
```
1738713600 - (72 * 3600) = 1738454400
```

When generating batches, use a reference timestamp and offset from it. The exact values matter less than the relative ordering.

## Platform Guidelines

### MyFace (Facebook-like)
- Casual, conversational status updates
- Life updates, opinions, daily activities
- Emoji usage: moderate (1-3 per post)
- Length: 50-280 characters typical
- NO hashtags
- Can tag other NPCs with @mentions

Example content by tone:
- happy: "Just got the promotion!! Can't believe it actually happened"
- bored: "Someone please tell me why I'm watching paint dry on a Saturday"
- chaotic: "3am thoughts: what if dogs think we're the pets and we just don't know it yet"

### InstaSnap (Instagram-like)
- Photo captions (describe the implied photo in media_urls)
- Aesthetic, visually-oriented
- 2-4 hashtags at the end
- Length: 50-200 characters before hashtags
- Focus on moments, aesthetics, vibes

Example formats:
- "Golden hour hits different #coffeetime #cityvibes" (media_urls: `'["sunset through coffee shop window"]'`)
- "New fit check #ootd #style" (media_urls: `'["mirror selfie in casual streetwear"]'`)

### Threadit (Reddit/Twitter hybrid)
- Opinionated takes, questions, stories
- Can be longer and more thoughtful
- Casual internet speak allowed
- NO hashtags
- Hot takes, observations, mini-rants welcome

Example formats:
- "unpopular opinion: cold pizza is actually better than hot pizza and I will die on this hill"
- "does anyone else feel like time moves differently on Sundays or is that just me"

## Character Consistency

When generating posts for a specific NPC, maintain:
1. **Voice consistency** - Same speaking patterns, vocabulary level, emoji habits
2. **Interest alignment** - Posts should reflect their stated interests/occupation
3. **Relationship awareness** - Can reference other NPCs they know
4. **Mood variety** - Mix of moods over time, not all posts same tone
5. **Time coherence** - Recent posts might reference earlier ones

## Generating Post Batches

When asked to generate posts for an NPC, create a realistic mix:
- 60% mundane daily life
- 20% interest/hobby related
- 10% opinions/hot takes
- 10% interactions with others (replies, mentions)

Spread posts across time realistically:
- Active users: 1-3 posts per day
- Average users: 3-5 posts per week
- Quiet users: 1-2 posts per week

## Cross-NPC Interactions

When generating posts that involve multiple NPCs:
- Use realistic interaction patterns (friends comment on friends)
- Reference shared events or inside jokes
- Create reply chains that feel natural
- Don't overdo it - most posts don't get comments

## Delivery

1. Output as a single JSON array file
2. Place in `server/data/seed/posts/` (create if needed)
3. Import via seed script or direct SQL INSERT
4. Each post needs an `id` generated at insert time (use `generateId()` from `server/src/db/index.ts`)

## SQL Import Template

```sql
INSERT INTO posts (id, npc_id, platform, content, media_urls, likes_count, comments_count, shares_count, created_at, content_rating)
VALUES ('{generated_id}', '{npc_id}', '{platform}', '{content}', '{media_urls}', {likes_count}, {comments_count}, {shares_count}, {created_at}, '{content_rating}');
```
